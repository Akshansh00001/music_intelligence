# Project roadmap

## Before presenting to a mentor/reviewer
- [ ] Replace synthetic demo with the official dataset.
- [ ] Confirm source licensing and API popularity-score definition.
- [ ] Audit incomplete dates and duplicate rows.
- [ ] Validate re-entry logic against 10 manually inspected songs.
- [ ] Run sensitivity checks with gap thresholds of 1, 2 and 3 days.
- [ ] Compare 3-, 7- and 14-day momentum windows.
- [ ] Add event/release dates if a licensed source is available.
- [ ] Export charts and document real-data findings with caveats.
- [ ] Deploy the Streamlit app and include repository/demo links in the resume.
